The Latency Challenge

Parsing Abstract Syntax Trees (AST) for documentation generation is computationally expensive. Doing this on the main thread froze the UI for 3-4 seconds per file upload.

Asynchronous Workers

Decoupled the parsing logic using Celery workers. Implemented a polling mechanism where the frontend checks Redis every 500ms for job completion, keeping the UI completely responsive.
